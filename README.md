# 💹 Real-Time Stock Market Data Processor — India Edition

A Python-based ETL pipeline that fetches **live stock prices** for Indian and global companies,
**converts all prices to Indian Rupees (₹ INR)** using live forex rates, performs automated
data cleaning with Pandas, outputs structured CSVs + JSON reports, and serves a polished
browser-based live dashboard.

## 🚀 Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/yourusername/financial-data-processor.git
cd financial-data-processor
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set your Anthropic API key (required for the dashboard's AI features)
```bash
# Linux / macOS
export ANTHROPIC_API_KEY="sk-ant-..."

# Windows Command Prompt
set ANTHROPIC_API_KEY=sk-ant-...
```

### 4. Fetch live stock data
```bash
python data_processor.py
```
This fetches live prices from Yahoo Finance, converts them to INR using live forex rates,
cleans the data with Pandas, and writes `outputs/report_latest.json` and `outputs/stocks_latest.csv`.

### 5. Start the local server
```bash
python server.py
```
> ⚠️ **Important:** The dashboard requires the Flask server to be running. Opening `dashboard.html`
> directly in a browser will **not** work because it needs the server to serve the report data.

### 6. Open the dashboard
```
http://localhost:5000
```

## 🔄 Refreshing Data

The dashboard reads from `outputs/report_latest.json` (generated by `data_processor.py`).
To see updated prices:

1. Run `python data_processor.py` again in a terminal
2. Click **Reload Data** in the dashboard (or wait — it auto-checks every 5 minutes)

## 🐛 Troubleshooting

| Problem | Fix |
|---|---|
| Dashboard shows "Could not load market data" | Run `python data_processor.py` first, then `python server.py` |
| `outputs/report_latest.json` not found | Run `python data_processor.py` — it creates the outputs/ folder |
| Forex rates show fallback values | Check internet connection; the er-api.com endpoint may be temporarily down |
| A stock shows no data | Yahoo Finance occasionally drops a ticker; try again in a few minutes |
| Server shows `ANTHROPIC_API_KEY is not set` | Set the env var: `export ANTHROPIC_API_KEY="sk-ant-..."` |
